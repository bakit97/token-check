# SOL·СКАН

[Открыть сайт](https://bakit97.github.io/token-check/).

Одна рабочая версия: `index.html` — основной интерфейс, `v2.html` перенаправляет на него. Допуск монет, фильтры «Прошли» и оба исследования считает сервер; телефон отображает опубликованные результаты. Неизвестные значения не заменяются нулями.

`server/` — единственный источник сборки сборщика. Выкладка проверяет манифест модулей и обновляет только изменившиеся файлы, сборщик — последним.

Данные:

- `source/` — журнал обнаружения и допуска, суточные счётчики с границей 00:00 UTC+5.
- `observations-v2/YYYY-MM-DD.json` — полные наблюдения с временем получения `at`.
- `observations-v2/summary/` — небольшие проекции для телефона.
- `passed-v2/` — серверный журнал совпадений с зафиксированными версиями условий.
- `research-v2/` — исследования на подтверждённых наблюдениях. Итоговые классы требуют полного окна и достаточного покрытия.

[Карта переноса наблюдений](docs/OBSERVATION-MIGRATION.md) · [Хранение и очистка памяти](docs/RETENTION.md) · [Бюджет](docs/RESOURCE-BUDGET.md) · [Управление настройками](docs/CONTROL-v2.md).

Для связи с Helius и облаком используются серверные учётные данные. Они не нужны браузеру и не должны попадать в репозиторий.
