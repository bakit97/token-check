# История активных монет

Старые наблюдения активной монеты сохраняются в неизменяемый пакет observations-v2/active-history/. Пакет содержит несколько монет, а не отдельную запись в GCS на каждый mint.

Перед сокращением горячих массивов сервер записывает пакет на диск, выгружает в GCS, читает его обратно и проверяет хеш каждого набора наблюдений. Только после проверки старые строки убираются из C/state.json. Последние 30 минут и максимум баланса остаются горячими. Полные дневные выгрузки и исследования читают объединённую историю. Снимки raw и ранние свечи сохраняют исходные времена получения.

Незавершённый пакет повторяется после сбоя. Отсутствующий локальный пакет восстанавливается из зеркала. Локальные пакеты без активных ссылок удаляются только спустя 48 часов; полные завершённые наблюдения уже хранятся отдельно. История и старые данные в GCS не удаляются.

Тесты проверяют отказ зеркала, одновременное появление новых наблюдений, перезапуск, восстановление локального файла, финальный архив и снижение размера state без потери строк. Порог health check не повышался.
