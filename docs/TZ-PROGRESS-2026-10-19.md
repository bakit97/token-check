Изображения берутся из имеющихся данных или metadata URI разрешённых публичных gateway. Загрузка ограничена по размеру/времени, без переходов по redirects и обращений к внутренним адресам. Необязательные метаданные больше не уничтожают уже полученную проверку прав mint при отсрочке RPC.

Пункт 2: passMode хранится отдельно для before/after. Все включённые модули выбранных уровней обязаны пройти. Старый журнал читается без изменения; collector переводит загруженную конфигурацию на новый режим, сохраняя её пороги.
