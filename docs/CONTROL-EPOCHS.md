# Новая эпоха исследований

В существующем owner control API добавлены POST `/api/research-one/new-epoch` и `/api/research-two/new-epoch`.

Тело: `{ "confirm": true }`. Используются прежние авторизация владельца, CORS и ограничение частоты. Без явного подтверждения ответ 422; без авторизации 401. Id и время запроса назначает сервер. Конкурирующая запись защищена поколением GCS.

Ответ 200 означает, что запрос принят. Коллектор применяет его при загрузке конфигурации; actual start виден в `research-v2/epochs.json` и в `research-v2/status.json.epoch` для И1. Настройки берутся из действующей конфигурации и не меняются. Повторное чтение одного запроса коллектором не начинает ещё одну эпоху.

Явная новая эпоха начинается без переноса монет прежней эпохи. Прежние файлы исследований сохраняются, банки выбранного уровня архивируются перед очисткой. Дозагрузка прежнего И1 архивируется отдельно, её payload-файлы сохраняются. Обычная смена порогов по-прежнему переразмечает существующие наблюдения.

Интерфейс не изменялся: при подключении кнопки сначала показать владельцу подтверждение, затем отправить POST. Проверять начало по публичному epochs.json, а не по локальным часам телефона.
