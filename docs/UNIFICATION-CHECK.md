# Проверка объединения — 18 октября 2026

Главная страница использует новый интерфейс. Старый интерфейс, классическое исследование и старые сериализаторы из сборщика удалены. `v2.html` сохраняет старую закладку перенаправлением на главную. Телефон читает точный серверный допуск также из свежей 30-секундной сводки; дополнительное ожидание двухминутного журнала убрано без новых RPC/выгрузок. Единственный источник сборки — `server/` с проверяемым манифестом 20 модулей.

Старые `day/`, `obs/`, `raw/`, `research/` перенесены в `archive/legacy/`: **4 627 объектов, 46 012 916 байт**. Сначала скопированы все объекты, затем проверены размеры и контрольные суммы всех копий и неизменность исходного списка; только затем оригиналы удалены с проверкой поколений. Итоговый список старых префиксов пуст. Публичное чтение архивного JSON проверено для каждого раздела.

Полная сверка трёх дней совпала: **1 509 496** строк DS, **137 485** замеров хранилищ, **23 238** записей состояний пула, **2 858** снимков держателей и **1 719** наборов свечей. Сохранены исходные времена получения. Это сверка доступных наблюдений: **142 старых файла raw/trades отсутствовали ещё до переноса**; повторная проверка их не восстановила. Старые исследовательские результаты не импортированы.

В процессе найдены и исправлены две регрессии: восстановление уже архивированных монет раздувало state; удалённый вместе со старым исследованием общий загрузчик настроек мешал запуску модулей. Выполнен аварийный откат, затем отдельная проверенная выкладка исправления. Проверка здоровья теперь требует активности Source, Passed и обоих исследований без ошибок конфигурации.

## Стартовые фильтры

Оба включены на уровне 1, для фаз до и после миграции. Окно решения — 15 минут после допуска.

| Условие | Базовый | Усиленный |
|---|---:|---:|
| Подтверждённый контракт без опасных прав | обязательно | обязательно |
| Уникальные покупатели в исходные первые 10 минут | ≥10 | ≥25 |
| Реальные SOL в подтверждённом хранилище | ≥5 | ≥10 |

Это стартовые пороги для наблюдений, а не результат обученного исследования. Покупатели отсекают единичную активность, SOL — почти пустые пулы; усиленный вариант требует больше активности и денег. Отсутствие измерения остаётся неизвестным. USD-ликвидность и виртуальные резервы не подменяют SOL.

Свежие миграции получили приоритет в очереди GeckoTerminal, неподдерживаемые пулы — отсрочку. Уже доказанное число покупателей внутри первых десяти минут используется как нижняя граница: оно может подтвердить «≥10», но недостаточная граница не доказывает отказ. Перекрывающиеся окна и разные пулы не суммируются. При ранней миграции учитываются только данные, действительно полученные внутри исходного окна mint; поздние покупки исключены.

## Проверки и оставшиеся ограничения

Linux CI, интеграционный поток Source → Passed → исследование 2, тесты хранения/бюджета и мобильный Chromium прошли. После каждой итоговой выкладки проверены свежая версия, все четыре модуля, DBC/LaunchLab, память, state и бюджет. В финальной серии снимков RSS: **194–210 МБ**, пик **219.2 МБ**, state **18.73 МБ**, оценка Helius **16.42–17.25 кредита/мин**. Это измеренный интервал, а не гарантия будущей нагрузки.

Исследование 1 реально наблюдает более 1 250 новых монет; итоговые классы ждут полного пятичасового окна и покрытия. Исследование 2 работает, но в момент проверки новых Passed-записей ещё нет: свежие монеты не подтвердили все три условия. Классы и сигналы ради заполнения не создавались.

Pump публикует суточные received/accepted, бюджетные паузы и явно приблизительную оценку пропусков. DBC/LaunchLab не отключаются ради бюджета; пауза Pump ограничена 90 секундами с последующей короткой проверкой. Коэффициент WS применяется к фактическим полученным UTF-8 байтам без округления блоками. **Сверка реального списания Helius ожидает два скриншота дашборда; billingVerified остаётся false.**

Control-api не развёрнут: Cloud Run API в проекте отключён. Экспорт настроек из интерфейса доступен. Размер VM и диска не менялся. **Нулевой счёт GCS не подтверждён:** частая свежая публикация продолжает расходовать операции; строгий месячный ограничитель записей выключен. Об этом отдельно сказано в [RESOURCE-BUDGET.md](RESOURCE-BUDGET.md).
